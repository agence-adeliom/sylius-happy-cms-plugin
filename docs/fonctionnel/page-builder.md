# Page builder

## What it is for
The page builder shows the page as visitors will see it, and lets editors change each block. The preview also works when the administration is served at another address than the website, for example "admin.example.com" and "www.example.com". Editors do not need to be logged in on the public website to see the preview.

## Who is involved
- **Editor (administrator)**: opens the builder, hovers and edits the blocks, saves, publishes.
- **Website visitor**: never sees the preview; drafts stay invisible to them.
- **Project technical team**: fills in the address of each channel and sets up the server security when the administration has its own address.

## Rules
- The preview opens through a limited link, valid 5 minutes by default, for one page and one language only.
- A preview link gives access neither to another page nor to another language.
- After each save, the preview reloads with a new link and goes back to where the editor was.
- In the preview, the links and forms of the page are disabled: the editor stays on the page being edited.
- Preview pages are neither publicly cached nor indexed by search engines.
- The light or dark theme of the administration applies to the markers of the preview.

## Special cases
- Preview link expired, altered or used on another page → access refused.
- Preview not answering within 10 seconds → a message asks to check the address of the page channel.
- Administration session expired while editing → a message asks to reload the builder.
- Preview showing another page than the one being edited → an alert asks to reload the builder, and editing is suspended.
- Editor without the editing right → the builder opens, but the preview stays empty with the "preview unreachable" message.

## Still to decide
